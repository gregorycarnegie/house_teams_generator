Entra ID CSV Generators

Offline tools for generating Entra ID distribution group CSV files from Bromcom and Active Directory exports.

All processing happens locally in your browser. No data is uploaded anywhere.

House & Year Groups

House & Year Teams Generator

Generate Entra ID CSV files for house and year group combinations. Matches students across Active Directory (Y12 & Y13), Bromcom, and Entra ID exports.

  • Upload 4 source files (AD Y12, AD Y13, Bromcom, Entra ID)
  • Automatic matching by email address
  • Generates CSVs for each house-year combination
  • Detailed missing matches and duplicate reports
 Class Distribution

Class Distribution Group Generator

Generate Entra ID CSV files filtered by class tags. Perfect for creating distribution groups based on subjects or class lists.

  • Upload 3 source files (Student Emails, Class List, Entra ID)
  • Filter students by class tags (e.g., MAT, SCI, ENG)
  • Optional split by year group
  • Processing log with detailed warnings

Privacy & Security: All files are processed entirely in your browser. No data is transmitted to any server.

Works offline once loaded. Compatible with modern browsers.
